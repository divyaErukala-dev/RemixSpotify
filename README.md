# Spotify Remix App

A responsive Spotify-inspired music streaming web application developed using **React JS, JavaScript, HTML5, and CSS3**. The project demonstrates practical implementation of React components, routing, authentication, API integration, state management, user interactions, and responsive web design.

## Project Overview

The Spotify Remix App provides a music-streaming-style user experience where users can log in, browse featured playlists, explore categories and genres, view new releases, open playlist and album details, and interact with songs.

The application uses API calls to retrieve and display dynamic application data and includes protected routes for authenticated users.

## Technologies Used

* React JS
* JavaScript
* HTML5
* CSS3
* React Router
* REST API concepts

## Key Features

* User login and authentication
* Protected routes for authenticated users
* Responsive Home page
* Featured playlists
* Categories and genres
* New releases
* Playlist details
* Category playlist details
* Album details
* Song information and playback
* Navigation between application routes
* Not Found page for invalid routes
* Responsive design for mobile and tablet views

## API Integration

The application uses HTTP requests to retrieve and display dynamic data, including:

* Login API
* Featured Playlists API
* Categories API
* New Releases API
* Playlist Details API

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/divyaErukala-dev/RemixSpotify.git
```

### 2. Open the project directory

```bash
cd RemixSpotify
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

### 5. Open the application

Open the local URL shown in the terminal in your web browser.
